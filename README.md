# 📝 To-Do App

A simple and responsive To-Do application built with modern frontend technologies. This project allows users to manage daily tasks efficiently by adding, updating, and deleting tasks, while demonstrating core frontend development concepts such as state management, component structure, and dynamic UI updates.

---

## 🚀 Features

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Dynamic task rendering
* Responsive design (works on mobile and desktop)
* Clean and intuitive user interface
* Ready for backend or persistent storage integration

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6+)
* React

## ⚙️ Getting Started

### Prerequisites

* Node.js
* npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/DamiiDev/To-do-app.git
```

2. Navigate into the project folder:

```bash
cd To-do-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm start
```

---

## 💡 How It Works

* Users enter tasks using the form
* Tasks are added dynamically to the task list
* Each task can be marked as completed or removed
* React state updates the UI instantly
